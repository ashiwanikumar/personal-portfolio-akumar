# API Server

Node.js backend server with REST APIs and authentication.

## Repository

<https://github.com/personal-portfolio-akumar/api-server.git>

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Production

```bash
npm start
```
