# Security Policy

## Reporting a Vulnerability

Please report security issues privately. Do not open a public GitHub issue for vulnerabilities.

Send the details to:

- Email: ashvanikumar109@gmail.com
- GitHub: https://github.com/ashiwanikumar

Include:

- A clear description of the issue
- Steps to reproduce
- Affected routes, files, or endpoints
- Any logs, screenshots, or proof of concept that help verify the issue

## Supported Project

Security reports are accepted for the current `staging` branch of this private repository.

## Sensitive Data

Do not commit `.env` files, private keys, certificates, credentials, access tokens, database URIs, or production secrets. Runtime secrets must be managed through environment variables.

## Response

Security reports will be reviewed as soon as practical. Confirmed issues will be fixed in a private branch before being merged.
